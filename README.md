# Drink Up

# Description
- This project will help a user track there water intake. Users can select the amount they drank in ml and work towards 2 liters.

# Features
- 2 liter goal
- 250 ml cups
- Adjuct intake
- Random water fact generator
- Water level and percentage display

# Tools
- HTML
- CSS
- JavaScript
- https://www.medicalnewstoday.com/articles/290814#15-benefits
- https://html-color.codes/blue

# Challenges/Learned
- A challenge was getting the water level to work/show and being able to un click the cups (it is still a work in progress but if you un click the previous cup the level will go down and if you refresh the page it goes back to 0)
- I learned how to use different elements and classes to make this project work accordingly
